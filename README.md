About

This repository contains my projects completed during the C++ Programming Internship at CodeAlpha.

The main objective of these projects is to improve programming knowledge, logical thinking, and problem-solving skills through practical implementation.

Projects

Task 1: CGPA Calculator

- Takes the number of courses as input.
- Accepts grade points and credit hours.
- Calculates total credits and grade points.
- Displays the final CGPA.

Task 2: Login and Registration System

- Allows users to register with a username and password.
- Checks login credentials.
- Displays success or error messages.

Task 3: Banking System

- Checks account balance.
- Deposits money.
- Withdraws money.
- Displays updated account balance.
